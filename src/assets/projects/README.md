# Project screenshots

Drop app screenshots here — they appear in the Projects app automatically
(grid-card hover preview uses the first image; the detail view shows all of
them in a device-framed carousel). No code changes needed.

## Convention

```
src/assets/projects/<slug>/01.png
src/assets/projects/<slug>/02.png
...
```

- Formats: `.png`, `.jpg`, `.jpeg`, `.webp`
- Ordered by filename — zero-pad (`01`, `02`, …) to control the sequence
- Mobile projects render in a phone frame (portrait shots work best);
  web projects render in a browser frame (landscape, ~16:10)
